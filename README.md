# 사이버 샌드위치 말랑이

3D 샌드위치를 마우스·터치·손동작으로 주무르는 웹 장난감입니다. 정적 파일만으로 동작하며 빌드 과정이 없습니다.

- 마우스: 클릭해서 꾹, 끌어서 쭈욱, 휠로 양옆에서 꾹, 빈 곳 드래그로 돌리기
- 터치: 한 손가락 꾹·쭈욱, 두 손가락 집기·벌리기
- 손 인식(웹캠/전면 카메라): 검지로 콕, 엄지+검지로 집어 쭈욱, 두 손으로 집으면 꾹

카메라 영상은 브라우저 안에서만 처리되며 저장하거나 전송하지 않습니다. 카메라는 HTTPS에서만 켜집니다.

포함 라이브러리: three.js 0.160.0 (MIT), MediaPipe Tasks Vision 0.10.14 + hand landmarker 모델 (Apache-2.0).
